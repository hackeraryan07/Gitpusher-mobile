Designed with Architectural Safety & Efficiency

🚀 Faster Scans & Uploads

Avoids slow sequential uploads by leveraging concurrent asynchronous coroutine threads. Files are pushed simultaneously utilizing high-concurrency tree mapping.

⛓️ OOM & Crash Mitigation

Designed specifically for low-specification mobile devices with limited RAM. Includes lazy file resolution (loading bytes in batches only when actively uploaded) and a rate-limiting Semaphore capped at 3 concurrent connections to prevent crashing on large project sizes.

📂 Deep Directory Mapping

Scans documents recursively in deep hierarchies. Auto-ignores clutter and workspace outputs like .git, build, node_modules, and binary directories to protect project hygiene and data limits.

📋 Granular Progress Stages

Never guess upload state: features detailed staging trackers from "Scanning structure" through "Concurrently uploading blobs", "Generating Git Trees", and "Finalizing Branch Reference".

Technical Setup & Installation

  1. Download the .apk bundle artifact file using the buttons above.
  2. Sideload/transfer the APK to your Android device model.
  3. Ensure you have allowed installations from unknown sources in Android App Settings.
  4. Log in with your custom GitHub Personal Access Token (PAT) securely inside the app and explore your repos seamlessly.
